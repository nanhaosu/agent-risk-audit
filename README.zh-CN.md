# Agent Risk Audit：代理风险评分的离线审计

这是进行中的研究工程，第一版公开离线工具和合成演示。研究问题是：目标关联确认／未确定是否改变输入表示对风险评分的影响。假设尚未完成独立审核和新来源验证。

工具保留来源、条件、重复、失败与缺失，对重复位置的全部响应隔离。统计准入重新核对计划、提示词哈希和原始评分，不只依赖ok标签。

运行见[英文README](README.md)。演示应得到10条合成记录、1条准入、9条排除；11项测试通过，4个评分／网络探针被阻止。无需模型API或GPU；依赖需提前安装。

没有已证实的新方法优势、官方比赛排名或已完成独立人审。代码兼容性不等于论文复现。JRH已有通用审计、代理轨迹和序数任务支持，本项目保留其来源与版权。
